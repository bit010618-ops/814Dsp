# Module and data map

- `full/source/`：章节、逐页转写、真题与组件内容模型。
- `full/tools/`：内容模型、PDF 生成和审计工具。
- `full/tests/`：内容模型与生成约束验证。
- `full/outputs/`：可复建的组件或最终 PDF 输出。
- `sample/`：已验证的版式样稿基线；`legacy_full/`：仅作可复用绘制资产基线，非当前成品。

# Permanent product constraints

- 不遗漏原课件唯一信息，保持原章节、知识点和顺序。
- A4 纵版、彩色、传统学术教材风；正文自然续排。
- 展示公式统一 11 pt；行内公式 17.5 pt、相对正文基线下移 3 pt；正式数学排版和竖式分数不可例外。
- 图、题图去水印和课件模板时不得损失任何有效技术信息；不清晰或被遮挡时修复或重绘。
- 每章正文（含本章公式总表）结束后，紧接“第 X 章真题整理”：按该章归属汇总重点精练与补充真题，不能把所有题面集中放到全书末尾；所有题目的完整答案统一置于书末“附录 F：真题整理详解”，并回填页码。章节真题页的大标题、页眉必须显示当前“第 X 章真题整理”；书末答案页的大标题、页眉必须显示“附录 F：真题整理详解”。页脚仅保留连续页码，不得残留“真题整理讲解序”、总真题区或其他错误分区标题；每次重排后必须逐页核对题面区、答案区的标题、页眉和页脚是否与所属分区一致。不得使用“真题整理讲解序”等未确认标题。

# Known risks

- 真题图重绘／修复和最终答案页码回填尚未完成。
- 当前工作区有未提交的内容模型、组件、诊断和临时文件；必须逐文件判断，禁止误提交。

# Latest decisions

1. 动画状态以技术信息完整且可读性最佳为准，不能机械使用最后一帧。
2. 图内文字、公式、刻度、图例、题注不得与线条、坐标轴或其他文字重合。
3. 对所有含横纵坐标的离散图、连续图和频谱图：纵轴与横轴交点就是横坐标零点；不得在纵轴旁另画“0”位置、另设零轴或让零样本与纵轴分离。原点数字仅出现一次，置于原点右下方（第四象限）且不压线；坐标轴、样本杆、刻度和标签均不得重叠。
4. 课堂圈画仅在承担必要解释时保留；否则恢复为干净教材状态。
5. 课内练习和真题使用纯白题干与自然书写区，不用黄色底、边框、横线或“练习”标签。
6. 跨章节题：独立小题可分置；关联题整体放在所需知识最晚章节。
6. 附录保留 A、B、C、D、E、F、I；不单列 G、H。
7. 封面、目录和附录采用蓝金教材风；目录、答案索引均以最终分页回填。
8. 可读性优先，但不得以此省略唯一推导、单位、图形标注或例题步骤。
9. 本讲义仅覆盖 DSP 基础知识；所有 MATLAB 函数、绘图、程序代码、音频读写和实验内容均排除在成品之外。
10. 正文例题标题统一写“例题”，不显示“源课件例题”或来源性措辞；来源追溯仅保留在内部内容模型与审计记录中。
11. 面向读者的成品仅称《数字信号处理讲义》：所有标题、图题、图注、旁注、练习、附录、页眉页脚及索引均不得出现“源课件”“源文件”“原始材料”“根据原课件”，也不得出现“参考/依据/改编自某课件（文件、材料）”等会把讲义表述成来源材料副本的措辞。讲义本身是唯一成品；内部内容模型和审计记录可保留追溯字段，但不得参与排版。
