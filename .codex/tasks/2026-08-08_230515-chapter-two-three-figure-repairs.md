# 第二章三幅图形教材级修复

## Objective

修复第二章中三幅已被用户指出的问题图：s 平面到 z 平面映射图、2015 年真题零极点图、2021 年真题相干解调与低通恢复图；先完成并视觉验收这三幅图，再继续新增讲义内容。

## Root cause

- 映射图在总装配时只保留组件的 `<main>`，导致组件局部 CSS 未进入总文档；SVG 依赖的 `.axis`、`.circle` 样式丢失，圆和路径退回 SVG 默认绘制。
- 零极点图的标签采用紧贴固定坐标的布局，纵轴箭头、`Im` 与“单位圆”发生冲突。
- 调制/解调图的 SVG viewBox 与末行文字共用边界，PDF 缩放后上方频谱和下方结构图缺少安全边距，出现裁切风险。

## Plan

1. 用回归测试规定三幅 SVG 的独立样式、标签安全区和完整 viewBox。
2. 以真实坐标关系重绘 s-z 映射；调整零极点图标注；扩大并重排调制/解调图。
3. 合成候选 PDF，逐页渲染检查，并仅提交本次图形修复相关文件。

## Status

Completed

## Result

- 以具备完整 s、z 坐标轴、虚轴、单位圆、频率点和周期重合说明的真实 SVG 重绘映射图；所有关键 SVG 样式改为内联，避免总装配遗漏组件局部 CSS 后退回默认黑色填充。
- 重排 2015 年真题零极点图的单位圆、`Im(z)`、原点与刻度标签，取消相互遮挡。
- 扩大并重排 2021 年真题调制/频谱/相干解调 SVG 的画布与三段垂直间距，消除截断风险。
