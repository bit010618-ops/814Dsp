# 原课件技术图边界复核

## 目标

将原课件中可复用的复杂 DSP 图仅作为技术图本体插入讲义：保留全部公式、箭头、结构支路和必要标注；去除课件页眉、校徽/水印、底部色条及原图号，并由讲义提供统一图题。

## 已完成

- 新增受控裁切工具 `full/tools/crop_source_figures.py` 与回归测试。
- 为第 4、5 章的 DIT/DIF 蝶形图、IIR/FIR 结构图、频率抽样图和快速卷积图建立独立图资产。
- 逐图复核裁切边界：不再截断并联型图的频率公式、频率抽样图的 `H_k(z)` 说明，或 FIR 二阶节图的末端支路。
- 对唯一需要全宽保留的并联型图，仅白化右上角校徽区域，保留完整技术画面。
- 删除过渡性的半句原课件文字，并使用讲义自己的图题而非原课件图号。

## 验证

- `full/tests/test_crop_source_figures.py`：覆盖非完整课件页、关键结构图边界、全宽并联图的水印遮除与完整公式起点。
- PDF 由本地 Chromium + 本地 MathJax 实际导出；最后一次导出：`tmp/dsp-main-body-clean-crops-v9.pdf`。
- 已逐页视觉检查第 4、5 章相关页，确认公式和结构支路未被裁切。

## 固定规则

1. 先完整保留技术内容，再裁外壳；不得为“裁得干净”而截断公式、文字、箭头或支路。
2. 只有完整、独立的技术图可以入书；任何出现在裁切边缘的半句原课件文字必须排除。
3. 课件页眉、校徽/水印、底部色条、来源说明与原图号默认不入书；必要时对孤立水印局部白化，不能损害技术内容。
4. 讲义使用自己的统一图题与编号。
