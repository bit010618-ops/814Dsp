# 循环索引下标记法统一

## Objective

将正文中所有以 `mod N` 表示的循环索引统一改为括号外下标记法，例如 `x((n-m))_N`；不改动公式的循环取值含义，也不影响页面中既有的完整 LaTeX 渲染。

## Plan

1. 先以回归测试锁定新记法并禁止正文残留 `mod N`；
2. 全局替换正文源中的循环索引公式；
3. 导出并检查 MathJax、公式完整性和受影响页面。

## Result

- 已将第 3 章和 DFT 系统输出中的全部循环索引从 `\bmod N` 形式改为括号外下标形式。
- 重新生成的 90 页正文 PDF 中，页面 47--50 的循环移位、共轭对称和循环卷积均显示为 `x((\cdot))_N` / `x((\cdot))_8`。
- 回归测试通过；整书 MathJax 导出得到 `unrendered=[]`、`pageErrors=[]`，汇总 HTML 不含旧 `mod N` 记法。
