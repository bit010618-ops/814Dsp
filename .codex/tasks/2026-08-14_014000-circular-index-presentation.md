# 循环索引括号外周期下标复核

## Objective

全书禁止在面向读者的公式中使用 `mod N`、`\bmod N` 或 `\operatorname{mod}` 表示循环索引；周期必须作为完整括号索引的外部下标排版，例如 `x\left((n+m)\right)_N` 与 `x^*\left((N-n)\right)_N`。

## Result

- 检索确认有效正文源文件与整书主输出均无旧 `mod N` 记法。
- 重新生成第三、四章正文输出及第三章 LSI 输出，确认旧缓存文件也已同步为括号外周期下标形式。
- 以最终 A4 PDF 第 49 页复核：循环移位、循环共轭对称及循环卷积均显示为完整括号后的周期下标，例如 `x^*((N-n))_N`，无 `mod N` 残留。
