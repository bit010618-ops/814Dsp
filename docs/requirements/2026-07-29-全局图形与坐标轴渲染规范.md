# 全局图形、图表与数学绘图规范

> 状态：被图形渲染核心命令整合；本文件保留为通用坐标轴细则
> 生效范围：全书、所有后续重做页面，以及第一章的逐图返工验收
> 优先级：高于既有的“方便复用截图”做法；完整综合命令见 docs/requirements/2026-07-29-图形渲染核心命令.md。

## 1. 先审计，再修改

修改任何含图页面前，必须先记录现有图的生成方式。以下实现均判定为不合格，必须改为专业绘图库或 SVG 的真实坐标渲染：

- HTML/CSS 方块、线段或字符拼接；
- Unicode 字符模拟坐标轴、箭头、杆图、波形或流程图；
- 依赖固定像素、绝对定位或截图裁切的图；
- 静态截图、低清图、带课件标题条、学校标识、水印或无关批注的图；
- 视觉上有裁切、重叠、贴边、错位、失真或标注不可读的图。

每张图都必须在图形审计清单中记录：图号/页面、类型、原实现、是否合格、重绘方式、桌面验收、移动端验收和修复结论。

## 2. 统一的真实绘图要求

- 所有函数曲线、坐标系、几何示意、信号波形、频谱、三维曲面和流程图，必须使用专业绘图库或 SVG 的真实坐标系统生成。
- 图内文字默认中文；标题、坐标轴、图例、数值标注和说明均须清晰、统一。
- 数学标签必须使用统一的 MathJax/KaTeX 公式组件，不能以普通文本或图片代替。
- 坐标、曲线、杆、图例和标签须由数据驱动定位；禁止用固定像素硬凑关系。
- 渲染应保持矢量优先；只有原图无法合理重绘且内容完整、高清、无水印时，才可暂时保留，并在审计中标为待替换。

## 3. 标准教材坐标轴

所有带坐标轴的图默认按教材图验收：

1. 横轴与纵轴完整，带明确箭头、原点、刻度和轴标签。
2. 轴线长度须略超出有效数据范围；图形与页面边缘保留舒适留白。
3. 根据内容决定是否呈现左半轴、右半轴、上半轴、下半轴；不能机械地只画第一象限或只画右半轴。
4. 第一根离散样本不得压在纵轴上；必要时自动平移取样位置或扩展左侧范围。
5. 标题、轴标签、数值、图例、曲线、杆、刻度及箭头必须自动避让，任何元素不得相互重叠。
6. 连续函数应正确显示间断点、渐近线和定义域边界；图形不得紧贴坐标轴或裁切。

## 4. DSP、信号与系统图形细则

- 离散时间序列必须用规范 stem 图，标清样本位置、索引和零轴。
- 连续时间信号必须绘制连续曲线，并合理处理采样点和不连续处。
- 幅频图与相频图必须分图绘制，分别注明幅度/相位及频率单位。
- 频谱图须保留正负频率或单边频谱的真实含义，不能为省事截去必要半轴。
- 所有考研数学、信号与系统、DSP 图默认采用中文标题和中文说明。

## 5. 空间图与投影

涉及空间区域、曲面、空间曲线或二重积分时，默认同时给出三维图与对应二维投影图。两图须共享清楚的变量、区域边界与方向说明，不能以仅一张模糊示意图代替。

## 6. 强制渲染验收

每次修改含图页面后，必须实际启动渲染流程，而非只检查代码：

1. 桌面端预览：检查坐标、曲线、图例、中文、数学标签、边距和控制台错误。
2. 移动端预览：检查响应式布局、标签避让、图例可读性、横向溢出与控制台错误。
3. 打印预览：检查 A4 下的线条、中文、公式、刻度和细节是否清楚。
4. 任一重叠、裁切、错位、贴边、乱码、低清或控制台错误，均视为验收失败，必须重做。

核心原则：真实坐标绘制、教材式坐标轴、中文清晰标注、无重叠无裁切、桌面与移动端实际验证。
