# 全局数学公式排版规范

> 本文件是 docs/requirements/2026-07-29-项目执行核心命令.md 的数学强制附录。

本文件为《数字信号处理讲义》的核心、强制性全局规范。所有公式均遵循：

> 完整 LaTeX 源码 → 统一数学公式组件 → KaTeX 或 MathJax 整体渲染

任何数学公式均不得由多个普通元素手工拼接。

## 1. 整体公式渲染

- 每个公式必须把完整 LaTeX 源码一次性交由 KaTeX 或 MathJax 渲染，优先使用 KaTeX；无法支持时才使用 MathJax，并加载 amsmath 等所需扩展。
- 行内公式使用 \(...\)；独立公式使用 \[...\]。
- 不得将等号、上下标、括号、分数、根号、条件或说明文字拆成多个元素分别定位。
- 不得使用普通 HTML、Unicode、CSS、SVG、Canvas、图片或人工定位模拟任意公式或公式局部。
- 渲染失败必须修正 LaTeX 源码或渲染器配置；不得降级为 HTML、CSS、SVG、Canvas 或图片拼接。

## 2. 括号和定界符

- 需要随内容高度变化的定界符必须由 LaTeX 自动伸缩，例如：
  \left(...\right)、\left[...\right]、\left\{...\right\}、
  \left|...\right|、\left\|...\right\|、\left\langle...\right\rangle。
- 单侧定界符必须用英文句点占位，例如 \left\{...\right.、\left....\right|。
- 禁止单独输入普通括号或大括号后以 font-size、transform、scaleX、scaleY 调整高度。
- 禁止绝对定位、flex、grid、手工 SVG、Canvas、图片或多个元素拼接括号与括号内内容。

## 3. 分段函数、方程组与多行推导

- 所有分段函数必须使用完整 cases 环境；每一行统一写为“表达式 & 条件”。例如：

    \[
    \delta(n)=
    \begin{cases}
    1, & n=0,\\
    0, & n\ne 0.
    \end{cases}
    \]

- 若当前渲染器确实不支持 cases，只允许使用完整的单个 LaTeX 公式：

    \[
    \delta(n)=
    \left\{
    \begin{aligned}
    1, &\quad n=0,\\
    0, &\quad n\ne 0.
    \end{aligned}
    \right.
    \]

- 大括号必须由 KaTeX 或 MathJax 按公式行数自动伸缩，并与所有行整体垂直居中；不得手动设置高度或字号。
- 方程组使用 cases；需要按等号对齐的多行推导使用 aligned，例如 a &= b\\。

## 4. 矩阵、公式结构与符号

- 圆、方、大括号矩阵分别使用 pmatrix、bmatrix、Bmatrix；行列式使用 vmatrix；双竖线矩阵使用 Vmatrix。
- 分数、根号、上下标、求和、连乘、积分、极限、偏导、导数、向量、绝对值、范数、内积、上划线、帽子、波浪号、箭头与映射，均必须使用标准 LaTeX 命令。
- 数学符号优先使用 LaTeX 命令：\ne、\le、\ge、\approx、\equiv、\pm、\mp、\in、\notin、\subset、\subseteq、\cup、\cap、\forall、\exists、\infty、\partial、\nabla、\delta、\Delta、\omega、\Omega、\theta、\lambda。
- 公式内的文字、单位和条件使用 \text{...}，不得在数学模式中混入未处理的普通句子。

## 5. 尺寸、容器与统一入口

- 公式整体只能在最外层容器统一控制大小；不得修改 KaTeX 或 MathJax 内部元素的 transform、line-height、letter-spacing 或 font-stretch。
- 公式不得被裁切、强制换行或拆散。较宽公式应在外层容器允许横向滚动，不得压缩数学结构。
- 项目必须使用唯一的数学公式入口（例如 MathFormula），任何页面、文档或动态生成内容均不得绕开该入口。

## 6. 强制验收

每次生成或修改含公式的页面后，必须检查：定界符是否随内容伸缩；分段函数大括号是否覆盖全部行；矩阵括号、根号、分数线、上下标、求和/积分/极限上下限、多行对齐是否正确；是否存在裁切、错位、重叠、基线不一致或字体不一致。

只要出现括号高度异常、符号错位、公式拆散、公式裁切或字体不一致，即视为不合格，必须回到标准 LaTeX 整体渲染修复。
