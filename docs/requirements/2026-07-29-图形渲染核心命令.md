# 图形渲染核心命令

> 状态：项目执行核心命令的图形强制附录
> 适用范围：数学、信号与系统、DSP、结构图、流程图、真题图、所有重绘及修订页面
> 替代关系：本文件整合并优先于此前所有分散图形要求；重复内容以本文件为准，不冲突内容全部保留。

## 一、先审计，后绘制，后实际验收

1. 修改任何含图页面前，先判定图形类型与现有生成方式，并记录图号、页面、原实现、问题、重绘方案和验收结果。
2. HTML/CSS 拼接、Unicode/字符模拟、固定像素硬编码、绝对定位硬凑、静态截图、低清或带无关课件元素的图一律不合格，必须改为专业绘图库或 SVG 的真实坐标渲染。
3. 图形必须先按类型选择正确画法，禁止把离散信号画成连续曲线、把连续信号误画成 stem 图、把结构图画成草图式连线。
4. 每次修改后必须实际启动渲染，完成桌面端、移动端和 A4 打印预览；检查图形、中文、公式、标签、响应式布局和控制台错误。仅改代码、不看最终渲染，视为未完成。
5. 任一重叠、裁切、贴边、错位、乱码、低清、线条交叉、公式标签错误或控制台错误，均为不合格，必须重做。

## 二、统一教材视觉

- 目标是“数学正确 + 图形语法正确 + 坐标规范 + 风格统一 + 标签清楚 + 无重叠 + 讲义级美观”。
- 默认简洁、规整、舒展、易读；不花哨、不用营销式渐变/阴影/装饰。配色不超过 2--3 个主色，轴线与数据可区分。
- 图内标题、图例、说明默认中文；数学变量和公式使用统一 MathJax/KaTeX 整体渲染。
- 所有标签、数值、图例、箭头、曲线、杆、节点和边框自动避让；不得用一味缩小字体掩盖问题。
- 多图并列时，字体、线宽、颜色体系、子图标题位置、坐标范围和图间距须统一；不得一图拥挤、一图空泛。

## 三、坐标图的标准教材轴

所有带坐标轴图必须具备：完整横纵轴、明确箭头、清楚原点、合理刻度、轴标签和舒适留白。

1. 轴线须略超出数据范围，箭头前后均保留可见轴线和留白；图形不得贴边。
2. 按数学含义决定显示左/右/上/下半轴；负时间、负索引或负幅值有意义时，必须显示相应半轴，不能机械只画第一象限。
3. 横轴变量须明确：离散时间为 n，连续时间为 t，角频率为 \omega，离散频率为 k，复平面为 Re(z)、Im(z)。
4. 原点 0、刻度、样值、标题和轴标签必须互不遮挡；必要时自动偏移标签或增加画布边距。
5. 所有数据、曲线、点、杆和标签必须由真实数据坐标驱动定位，禁止像素拼凑。

## 四、信号、频谱与响应图

### 1. 离散序列与冲激

- 离散序列、DFS/DFT 序列、卷积结果必须使用规范 stem 图：每个整数索引一根竖杆，杆顶有样点，正值向上、负值向下，零轴清晰。
- 第一根样本不能压在 y 轴上；n=0 的刻度数字不能压在杆底。必要时扩展左边界或偏移纵轴。
- 负索引有意义时必须完整显示；样值过密时仅标关键样值，但不能导致位置含义不清。
- 离散冲激用单根箭头/杆，标明位置和权重；阶跃必须显示正确的跳变时刻与前后高度。

### 2. 连续时间信号

- 使用连续曲线；正确显示定义域、分段连接/断开、跳变、冲激、渐近线和关键时刻。
- 不能把离散采样点与连续波形混为一类；需要同时展示时，二者分别绘制并明确说明。
- 周期信号至少展示一个完整周期，必要时展示两周期以体现规律。

### 3. 幅度、相位、实虚部和频谱

- 幅度图与相位图默认分开绘制，频率范围一致；幅度明确非负，离散频谱使用 stem 或离散谱线，连续响应使用连续曲线。
- 相位必须明确主值范围（默认优先 (-\pi,\pi]），跳变处断开或正确折返；幅度为零处不得随意标相位。
- DTFT/频率响应按题意标记 0、\pm\pi/2、\pm\pi、2\pi 等关键频点；DFT/DFS 标出 k=0,\ldots,N-1。
- 实部与虚部默认分开；若利用对称性，图中应可见相应的奇偶/共轭关系。

### 4. 零极点图

- 横轴 Re(z)、纵轴 Im(z)，两轴严格等比例；单位圆必须为真正圆形并留有边距。
- 零点使用空心圆，极点使用叉号；重根/重极点、\pm1、\pm j 和 ROC（如题目需要）须正确、清楚地标出。
- 不得用大概位置代替真实计算结果；任何标签不得压住单位圆、零点或极点。

## 五、空间图

涉及空间区域、曲面、空间曲线或二重积分，默认同时给出三维图及对应二维投影；变量、方向、边界和区域对应关系必须清楚。

## 六、DSP / 信号与系统结构图

### 1. 共通结构语法

- 一律使用矢量化真实布局；主信号默认左到右，输入在左、输出在右，反馈从上方或下方规整回接。
- 模块对齐到统一网格，间距均匀，线条优先横平竖直；禁止无意义斜线、乱线、线穿文字、箭头贴框、模块忽大忽小。
- 加法器使用标准圆形求和节点并标清 + / -；延时器使用统一矩形 z^{-1}；增益/乘法器用清晰系数块；分支点为实心圆；每条信号线均有清楚箭头。
- 模块框、箭头、节点、延时器和增益块的尺寸、线宽、字体与间距必须全图统一；数学标签通过统一公式组件渲染。

### 2. 结构关系必须一眼可辨

- 直接型 I：两条延时链、前向 b_k 与反馈 a_k 支路、求和关系必须正确。
- 直接型 II：共享延时链、内部状态、输入和输出支路必须清楚。
- 转置型：必须真实反映转置后的分流和汇合，不能仅改外形。
- 级联型：子系统沿主线依次串接，每级 H_1(z),H_2(z),\ldots,H_m(z) 清楚独立。
- 并联型：输入先分支，各支路独立且上下整齐，最终汇至标准求和节点；每支路对应正确展开项。
- 差分方程实现：b_k、a_k、延时数量、前向/反馈位置与方程一一对应。
- 多速率系统：上采样明确标 \uparrow L，下采样标 \downarrow M，滤波器与采样率变换器顺序、支路和汇合关系正确。

### 3. FFT 蝶形图

- 必须按 stage 分列：输入左、输出右、上下节点对齐、各级列距均匀，蝶形单元大小一致且对称。
- 清楚标出加/减关系、DIT 或 DIF、旋转因子 W_N^k 和必要的自然序/位逆序说明；旋转因子贴正确支路但不压线。
- 禁止把蝶形图画成杂乱流程图、随意绕线或上下节点失齐。

## 七、图形验收清单

交付前逐图核验：

1. 图的类型和数学含义是否正确？
2. 是否为专业绘图库/SVG 的真实坐标绘制？
3. 坐标轴、箭头、原点、刻度、范围、标签和留白是否齐全？
4. 离散/连续/幅相/零极点/结构图的专用语法是否正确？
5. 是否存在任何文字压线、标签重叠、第一杆压轴、图例遮挡、线条交叉或边缘裁切？
6. 多图是否统一，中文与数学标签是否清楚？
7. 桌面、移动端、A4 打印预览和控制台检查是否全部通过？

核心原则：图不只是“内容画对”，还必须“图形语法画对”；最终每一张都应像教材、讲义或规范考试答案中的正式插图。

## 八、实现禁令与响应式

- 禁止用 div/span/border、空格、HTML 表格、CSS transform、随机路径或不断叠加 margin/translate/absolute 补丁模拟任何数学图或结构图。
- SVG 必须使用真实 viewBox；Canvas 必须适配 devicePixelRatio；窄屏优先减少次要刻度、移动图例、增加画布或引入引导线，不能把整张图缩小到文字不可读。
- 输出前同时检查深色与浅色预览、导出图完整性和控制台错误。
