# 数字信号处理讲义项目执行核心命令

> 状态：全项目最高优先级、强制执行
> 覆盖范围：所有章节、正文、例题、真题、公式、图形、结构图、附件、PDF 与可修改源文件
> 使用方式：任何制作、修订、重排或验收前必须执行本命令；下列附录为本命令的一部分，不是可选参考。

## 1. 成书与版面

1. 保留原课件的唯一知识内容、原知识顺序、题目原文与必要图示；只合并动画递进造成的重复页。
2. 正文连续自然续排：非章节末页、非真题一题一页的作答区，不得留下大面积空白。能安全放入下一段标题、导语、公式、图题、步骤或段落时必须前移。
3. 任何内容不得重叠、裁切、贴边、溢出或出现乱码；图和公式必须作为完整内容块保留。
4. 成品为 A4、彩色打印、传统教材风；页眉、页脚、目录、字号、公式大小、中文字体和配色全书统一。
5. 不输出 MATLAB、代码、音频实验、来源说明、课件页码、学校标识、水印或“源文件/原课件”类读者可见文字。

## 2. 数学公式的唯一渲染路径

1. 所有公式必须走同一组件：完整 LaTeX 源码 -> MathJax 或 KaTeX 整体渲染。严禁普通 HTML、Unicode、CSS、SVG、Canvas、图片或拆分元素手工拼接公式。
2. 行内公式使用 \( ... \)，独立公式使用 \[ ... \]；上下标、分数、根号、积分、求和、矩阵、定界符、箭头和数学符号均使用标准 LaTeX 命令。
3. 分段函数、方程组、条件定义和多行推导必须使用 LaTeX 的 cases/aligned 等标准环境；大括号、括号、范数等由 \left/\right 或渲染器自动伸缩，禁止手调字号、CSS 拉伸、绝对定位或图片代替。
4. 公式容器不得裁切或破坏结构；宽公式允许整体横向处理，禁止把一个数学结构拆散强行换行。
5. 每次含公式页面生成后，检查括号伸缩、分数线、根号、上下标、多行对齐、公式基线、裁切和重叠；任何错误都必须回到完整 LaTeX 源码重渲染。

数学细则附录：docs/requirements/2026-07-29-全局数学公式排版规范.md。

## 3. 图形的唯一渲染路径

1. 含图页面修改前先审计图形类型和原生成方式。HTML/CSS 拼接、字符模拟、固定像素硬编码、绝对定位硬凑、静态截图和低清裁图均不合格，必须使用专业绘图库或 SVG 的真实坐标/真实布局重绘。
2. 每张图均须做到数学内容正确且图形语法正确；标题、中文说明、数学标签、图例、坐标、线条和留白统一且无重叠。
3. 图形必须像教材、讲义或规范考试答案中的正式插图，不接受“基本看懂”的草图。

图形与坐标轴细则附录：docs/requirements/2026-07-29-图形渲染核心命令.md 和 docs/requirements/2026-07-29-全局图形与坐标轴渲染规范.md。

## 4. 坐标图、信号图和频谱图

1. 所有坐标图使用标准教材轴：完整横纵轴、明确箭头、清楚原点、合理刻度、轴标签、舒适留白，轴线略超出数据范围；按含义显示必要的负半轴。
2. 离散序列、DFS/DFT 序列与卷积结果使用规范 stem 图；第一根样本和原点数字不得压 y 轴。
3. 连续时间信号使用连续曲线，正确处理定义域、间断、冲激、阶跃、渐近线和周期。
4. 幅度与相位分图，频率范围统一；相位主值与跳变正确；离散频谱不得画成连续光滑曲线。
5. 零极点图严格等比例，单位圆为真圆，零点空心圆、极点叉号，重数/ROC/关键点按题意清晰表现。
6. 空间区域、曲面、空间曲线或二重积分默认同时给三维图和二维投影。

## 5. DSP / 信号与系统结构图

1. 采用标准元件：求和器、延时器 z^{-1}、增益块、分支点、箭头、模块框；同类尺寸、线宽、字体、间距全图统一。
2. 主信号默认由左至右；结构图对齐网格、横平竖直、间距均匀；反馈、分支、汇总清楚，禁止乱线、斜线、线穿文字和线条交叉。
3. 直接型 I/II、转置型、级联型、并联型、差分方程、多速率结构必须表达真实拓扑，系数和延时链与数学方程一一对应。
4. FFT 蝶形图按 stage 分列、上下节点对齐、单元对称，旋转因子 W_N^k 位于正确支路。
5. 级联型一眼看出串接，并联型一眼看出分路汇总；系统框图一眼看出主信号流与反馈流。

## 6. 实际验收与交付门槛

1. 修改后必须启动实际渲染：桌面端、移动端和 A4 打印预览均需检查坐标、曲线、图例、中文、数学标签、响应式布局和控制台错误。
2. 任何重叠、裁切、贴边、错位、字体不一致、标签压线、坐标不完整、图形语法错误、乱码、低清或控制台错误，均为失败，不得交付。
3. 每章完成后先按本命令逐页审计；仅通过全部验收的完整章节 PDF 才能进入根目录 output/，然后进行任务范围内提交和推送。

核心总原则：内容完整、公式整体渲染、图形真实坐标绘制、教材级图形语法、自然连续版面、无重叠无裁切、桌面/移动端/A4 实测通过。

## 7. 工具选择、统一组件与响应式

1. 数学函数、信号波形和频率响应优先使用 Plotly、Matplotlib 或同级专业数学绘图库；几何图、结构图、框图和蝶形图优先 SVG、TikZ、Graphviz 或程序化矢量布局；三维图使用 Plotly 3D、Matplotlib 3D 或 Three.js；简单流程关系可使用 Mermaid。
2. 项目必须形成统一组件入口：MathFormula、MathPlot、SignalPlot、StemPlot、SpectrumPlot、PoleZeroPlot、ButterflyDiagram、FilterStructure、SystemBlockDiagram、ThreeDPlot。同类图不得在页面中各自临时绘制。
3. 组件须接受真实数据、公式或拓扑作为输入，统一提供坐标范围、箭头、刻度、标题、标签、图例、导出和标签避让；不同页面不得再编写互不一致的固定坐标补丁。
4. 图形宽度必须适应容器；SVG 使用 viewBox，Canvas 适配 devicePixelRatio。窄屏应减少次要刻度、移动图例或扩大画布，而非盲目缩小整图；深色/浅色预览均应可读。
5. 三维图除题目明确不需要外，保留 x、y、z 轴、合理视角和相同数据的二维投影；曲面/曲线必须由真实函数和足够采样密度生成。

## 8. 结构与数学的一致性复核

1. 由差分方程绘制的结构图，必须可由结构图反向写回完全相同的方程；延时个数、b_k/a_k、正负号、前向/反馈路径不得错置。
2. 卷积、翻转、移位、尺度变换的坐标必须由变换公式计算；多步骤图保持统一坐标范围，动画帧不得造成轴线跳动。
3. 零极点、ROC、因果性和稳定性之间必须相互一致；FFT 的 DIT/DIF、旋转因子及自然序/位倒序必须明确且可验证。
4. 任何新公式或图形生成后，除了视觉检查外，还须检查专业图形语法和数学关系本身；“代码已运行”或“看起来差不多”均不能构成验收。
