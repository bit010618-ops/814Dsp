# 公式导出完整性约束

适用于本讲义的所有面向读者 PDF。

1. 导出前必须以浏览器完成 MathJax 排版后的完整 DOM 为准验收，不能只抽查个别公式。
2. DOM 中必须至少存在一个 MathJax 渲染容器；缺失即视为公式引擎未成功工作。
3. DOM 中不得残留 `\(`、`\)`、`\[`、`\]`。任一残留均表示公式仍以 LaTeX 源码形式存在，导出必须失败。
4. 本约束覆盖行内公式与独立公式；不得用普通文本、Unicode、CSS、SVG 或图片替代未渲染数学内容。

验收原则：完整 LaTeX 源码 → MathJax 整体排版 → 实际 DOM 检查 → PDF 导出。
